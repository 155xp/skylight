These Wayland protocol descriptions are copied unchanged from KDE's plasma-wayland-protocols
(`/usr/share/plasma-wayland-protocols` on Debian) and keep their own license headers
(LGPL-2.1-or-later). Skylight generates its client bindings from them at build time.

- `zkde-screencast-unstable-v1.xml`: KWin's privileged screencast (PipeWire node per output)
- `fake-input.xml`: KWin's fake input (pointer, keyboard, touch)
